# Changelog

## 0.1.0 (2026-08-11)


### ⚠ BREAKING CHANGES

* **ci:** publish to nuget.org with Trusted Publishing instead of a stored key ([#148](https://github.com/MarcelRoozekrans/Rag.NET/issues/148))
* **options:** make every configure callback able to configure something ([#144](https://github.com/MarcelRoozekrans/Rag.NET/issues/144))
* **reranking:** stop the reranker silently deciding how many chunks an answer uses ([#145](https://github.com/MarcelRoozekrans/Rag.NET/issues/145))
* **gmail:** the query was never applied, and the options could not be set at all ([#141](https://github.com/MarcelRoozekrans/Rag.NET/issues/141))
* **mcp:** the HTTP transport served everything unauthenticated by default ([#131](https://github.com/MarcelRoozekrans/Rag.NET/issues/131))
* **graphrag:** delete Mode, a public setting nothing ever read ([#125](https://github.com/MarcelRoozekrans/Rag.NET/issues/125))
* **chunking:** fold TokenAware and Semantic into Rag.NET.Chunking
* **dataproviders:** merge the four Graph connectors into Rag.NET.DataProviders.Microsoft365
* **parsers:** merge Word, Excel and PowerPoint into Rag.NET.Parsers.Office
* **resilience:** extract the resilience cluster into Rag.NET.Resilience
* **storage:** extract SQLite persistence into Rag.NET.Storage.Sqlite
* **templates:** EmailChunkingOptions.RegisterParser and QAPairsChunkingOptions.RegisterParser are gone. Use UseEmailChunking(registerParser: false) and UseQAPairsChunking(registerParser: false).
* **templates:** Rag.NET.Chunking.Templates.EmailDocumentParser is now EmailTemplateDocumentParser. Free before 4.1 ships packages, expensive after.
