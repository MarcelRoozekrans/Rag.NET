# Milestone 1: Release Readiness (v1.0)

**Status:** active
**Started:** 2026-07-24

## Goal

Make Rag.NET shippable as a v1.0 release: a CI pipeline that builds, tests, and produces
NuGet packages reproducibly from a clean checkout; configuration aligned on IOptions with
ZeroAlloc validation; consistent structured logging; first-class OpenTelemetry wiring; and
runnable sample applications plus a CLI tool so new users can evaluate the library in minutes.

## Definition of Done

- [ ] All planned phases complete
- [ ] Full solution builds 0 warnings / 0 errors from a clean restore
- [ ] All non-Docker unit test projects passing
- [ ] CI pipeline builds, tests, and produces NuGet packages
- [ ] Release tagged v1.0
